面向具身智能的数据采集与训练系统设计 进行中

Embodied-Intelligence Data Collection and Training System

围绕具身智能的数据采集流程与训练系统做设计：基于 UR7e 和 ARX X5 机械臂搭建数据采集平台，用 ROS 2 + LeRobot 管理多模态数据，基于 Diffusion Policy 等生成式策略模型做训练与评估，目标是让采集到的数据真正能用于训练。

Designing the data collection workflow and training system for embodied intelligence: a data collection platform built on UR7e and ARX X5 arms, multimodal data managed with ROS 2 + LeRobot, and training and evaluation built on generative policy models such as Diffusion Policy — so the collected data can actually be used for training.

毕业设计 · 具身智能 · UR7e / ARX X5 · ROS 2 · LeRobot · Diffusion Policy

BL618 桌面机器人 2025

BL618 Desktop Robot

基于博流 BL618 开发板的桌面机器人。LVGL 做的图形界面，Wi-Fi 联网后通过 NTP 对时，调用和风天气 API 显示时间和天气；还接了 OpenAI 的语音代理，可以直接语音对话。屏幕、天气、语音三个模块都跑在板子上。

A desktop robot built on the Bouffalo BL618 board. An LVGL interface shows time and weather — synced over NTP via Wi-Fi and fetched from the QWeather API — and an OpenAI voice agent enables direct voice chat with ChatGPT. Display, weather and voice all run on the board.

BL618 · LVGL · Wi-Fi · NTP · 和风天气 · 语音对话

多传感器闭环宠物喂食器 2026

Multi-Sensor Closed-Loop Pet Feeder

STM32 + FreeRTOS 的多传感器闭环喂食器：VL53L0X 测距判断食盆余量，HX711 称重、光敏传感，HC-05 蓝牙连接，SG90 舵机控制投喂，LVGL 触屏做交互。还加了 OV2640 摄像头和网页宠物识别，识别成功后经蓝牙回传触发舵机，全流程闭环，并生成了完整实验报告。

A multi-sensor closed-loop feeder on STM32 + FreeRTOS: VL53L0X ranging checks the bowl, HX711 weighing, light sensing, HC-05 Bluetooth, and an SG90 servo dispenses food, with an LVGL touchscreen for control. An OV2640 camera plus web-based pet recognition triggers the servo over Bluetooth when the pet is recognized — the whole loop is closed. A full experiment report was written for it.

STM32 · FreeRTOS · VL53L0X · HX711 · 蓝牙 · 传感器融合

雷达信号处理实验 2025

Radar Signal Processing Experiments

两组雷达实验的数据处理与汇报。S 波段 FMCW 雷达（2.37–2.47 GHz）做 MTI/MTD 处理；TI DCA1000 + AWR1642 毫米波雷达的原始 ADC 数据做脉冲压缩、距离–多普勒成图和交互式极坐标图，再用 KNN 做目标/杂波分类控制虚警。数据是真实采集的俯卧撑、手势、骑车等场景。

Signal processing and reporting for two radar experiments: MTI/MTD on an S-band FMCW radar (2.37–2.47 GHz), and pulse compression, range–Doppler imaging and interactive polar plots on raw ADC data from a TI DCA1000 + AWR1642 mmWave radar, with KNN target/clutter classification to control false alarms. The data is real — push-ups, gestures, cycling and more.

FMCW · 毫米波 · MTI/MTD · KNN · MATLAB

GNN 巨型低轨卫星网络链路重构 2025

GNN Link Reconstruction for Mega-LEO Networks

用图神经网络为巨型低轨卫星网络故障后的拓扑快速生成新链路：MATLAB 实现 GNN 训练与推理，研究“神经泛洪传播”（图卷积 + 注意力机制）替代传统贪心算法，目标是最少转发实现最广覆盖，并和贪心基线做了对比，前后做了五次汇报。

Using graph neural networks to regenerate links quickly after faults in a mega-LEO satellite network topology. The work studies "neural flooding propagation" (graph convolution + attention) as a replacement for greedy algorithms, aiming for the widest coverage with the fewest forwards, and compares against a greedy baseline across five progress reports.

图神经网络 · GCN · GAT · MATLAB · 卫星网络

碳化硅外延层厚度测量建模 2025

SiC Epilayer Thickness Measurement Modeling

基于红外光谱的碳化硅外延层厚度测量建模：七千多组波数–反射率数据（10°/15° 两种入射角），经傅里叶频域分析反推膜厚；把流程封装成 MATLAB 函数，批量扫描窗函数和平滑参数，统计厚度分布的直方图、均值和标准差。

Modeling SiC epilayer thickness measurement from infrared spectra: over 7,000 wavenumber–reflectance data points at 10° and 15° incidence, analyzed in the Fourier domain to recover film thickness. The pipeline was wrapped into MATLAB functions that batch-scan window functions and smoothing parameters and report the thickness distribution.

红外光谱 · FFT · MATLAB

Marigold · YOLOv11 · CUDA · 相机标定
